# 🌍 Tripadvisor Clone — Travel Discovery Website

A responsive travel website inspired by Tripadvisor, built using **HTML and CSS** with interactive frontend features using JavaScript. The project helps users explore travel destinations, hotels, restaurants, activities, and flights through a clean, modern interface.

## ✨ Features

- 🏨 **Hotels:** Explore hotel cards with images, sample ratings, prices, and search options.
- 🎟️ **Things to Do:** Discover attractions, sightseeing spots, nature escapes, and adventure activities.
- 🍽️ **Restaurants:** Browse restaurant information and food-related travel options.
- ✈️ **Flights:** Enter departure and destination cities, select travel dates, and view sample flight results.
- 💱 **INR Currency Page:** Learn about the Indian Rupee through a dedicated page with travel images and animations.
- 🔍 **Search and Filters:** Search for activities and filter listings by category.
- 🎨 **Modern UI:** Attractive layouts, image cards, hover effects, and CSS animations.
- 📱 **Responsive Design:** Layouts adapt to desktop, tablet, and mobile screens.
- 🧭 **Multi-page Navigation:** Navigate between different sections using separate HTML pages.

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling, responsive layouts, transitions, and animations
- **JavaScript** — Search interactions, category filters, and form validation
- **Remix Icon** — Icons
- **Google Fonts (Inter)** — Typography
- **Unsplash** — Travel and destination images

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure the HTML files and `style.css` are in the correct locations.
4. Open `index.html` in your browser, or run it using the Live Server extension in VS Code.
5. Use the navigation menu to explore Hotels, Things to Do, Restaurants, Flights, and INR.

## 🎯 Project Objective

The goal of this project is to practise frontend web development by building a multi-page travel website with responsive layouts, reusable styling, interactive elements, and an engaging user experience.
